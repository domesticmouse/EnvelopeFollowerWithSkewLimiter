# Build & Manufacturing Checklists

Step-by-step checklists for ordering, verifying, assembling, and bringing up the **6 HP Envelope Follower with Skew Limiter** main PCB and mated front panel.

## Workflow Order

| Step | Checklist | Scope |
| :---: | :--- | :--- |
| **1** | [`01-main-board-ordering.md`](01-main-board-ordering.md) | Main-board Gerber/BOM/CPL export, JLCPCB PCB fabrication specs (lead-free, `F.SilkS` QR replacement, tented vias), and Bottom-Side Economic PCBA ordering |
| **1b** | [`01b-front-panel-ordering.md`](01b-front-panel-ordering.md) | 6 HP × 3U bare front panel Gerber/drill verification and JLCPCB ordering (`Matte Black` + `ENIG-RoHS` + `White` silkscreen, `B.SilkS` QR replacement, combined cart) |
| **2** | [`02-pcba-part-alignment.md`](02-pcba-part-alignment.md) | Per-component placement & orientation verification for all **50 `B.Cu` SMD parts** in the JLCPCB placement viewer before checkout |
| **3** | [`03-tayda-ordering.md`](03-tayda-ordering.md) | Shopping checklist for all **18 through-hole / panel parts** (`RV1`–`RV4`, `SW1`–`SW2`, `LED1`, `J1`–`J4`, `J_PWR`, `C1`–`C2`, `C7`, `C11`–`C13`) plus knobs (`<= 14.0 mm` OD), power cable, mounting hardware, spares, and optional test loops |
| **4** | [`04-hand-assembly.md`](04-hand-assembly.md) | Post-PCBA inspection, optional `TP1`–`TP12` test loops, `B.Cu` THT parts (`J_PWR`, `C1`/`C2`, film caps), `LED1` polarity bench check, `F.Cu` front-panel dry-fit & soldering, and flux cleanup (with `3` overview maps and `18` per-part placement cards generated by [`generate_hand_assembly_images.py`](generate_hand_assembly_images.py)) |
| **5** | [`05-board-bringup.md`](05-board-bringup.md) | Unpowered cold checks, current-limited first power-up, all **12 test points** (`TP1`–`TP12`), stage-by-stage signal verification, `SLEW IN` / `SMOOTH` / `FAST-SLOW` / `OFFSET` / `LED1` tests, and troubleshooting |
